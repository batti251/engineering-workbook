# EngineeringWorkbook

This repository is my personal learning and growth space for engineering

I didn't want to just document my engineering knowledge in Notion. 
That's why I am building my own knowledge platform. 
As I learn new topics, I continue to develop the platform at the same time. 
As a result, the application not only documents my knowledge — it's architecture also reflects my growth as an engineer.



## current Features 
- 🚀 Angular V.22 project
- 📦 Backend with Supabase
- 🔒 Easy Email Authentification and Permission Policy  
- 📚 individual Documentation
- 📝 CRUD Functions for individual Documentation
